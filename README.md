# Disney plugin for Lampa

Adds a **Disney** item to the Lampa side menu. It opens a page of TMDB rows:
New on Disney+, new Disney movies, Pixar, Walt Disney Animation, Marvel, Star Wars,
Walt Disney Pictures, Disney Junior, Disney Channel, Disney classics and top-rated Disney.

Install: Settings → Extensions → Add plugin →

```
https://aaramg.github.io/lampa-disney/disney.js
```

Built for Lampa 3.x and written in ES5, so it runs on older Android TV WebViews.
